# 持续开发目标：消失博主的互联网存档

## 目标

博主被封号、资料被重置或注销之后，在抖藏家里点进去，依然能看到 Ta 原来的样子和尽可能多的作品。

## 完成标准

全部满足才算完成：

1. 收藏过作品的博主都至少检查过一轮，新消失的博主在 14 天内被发现。
2. 博主消失前，Ta 的全部公开作品清单（文字、封面、发布时间）已经存下，不只是收藏过的那些。
3. 存档主页里，没存视频的作品也能看到封面和文字，并标明“视频没有存下来”。
4. NAS 重启后服务会自己恢复，不再需要手动启动。
5. 有博主新消失时会通知用户。
6. 用户在真机上确认过作品页和存档主页。

## 每一轮怎么做

1. 先看线上健康状况和检测进度，再从上往下取一项待办。
2. 写代码和测试，全部通过后提交，推送到 `origin main`。
3. 需要上线时：先备份数据库并给旧镜像打回滚标签，等同步空闲再切换。
4. 界面改动要看到真实画面再算完成；App 有改动就发一版 TestFlight。
5. 勾掉待办，把结果记到下面的进展记录。

## 必须停下来问用户的情况

- 需要用户登录、授权或做真机验收
- 可能删除或覆盖用户数据，或要动 `.env`、`compose.yaml`
- 预计新增占用超过 50 GB
- 提交 App Store 审核或对外公开任何内容
- 触发抖音限流、验证码，或抖音登录失效（不绕过验证码）
- 同一个问题连续两轮没有进展
