# 留影界面设计系统

## 概念基准

- 桌面：`docs/design/archive-desktop-concept.png`，原生画布 1506 × 1047。
- 移动：`docs/design/archive-mobile-concept.png`，原生画布 853 × 1877，目标实现视口 390 × 844。
- 概念图只定义视觉与布局；实际文字、图标、媒体、进度和控件均由 React 原生渲染。

## 设计方向

- 主题：炭黑沉浸式本地媒体浏览器，不使用纯黑。
- 背景：`#0c0e11`；升高表面：`#15181d`；悬浮表面：`#20242a`。
- 主文字：`#f7f8fa`；次文字：`#969ba5`；分隔线：`rgba(255,255,255,.09)`。
- 唯一强调色：低饱和珊瑚红 `#f16761`。
- 字体：Geist 风格系统无衬线；中文回退到 PingFang SC、Noto Sans SC。
- 图标：Phosphor 线性图标，统一 `1.5` 笔画。
- 圆角：控件 10 px、媒体 12 px、移动抽屉 28 px；不用大面积卡片堆叠。
- 动效：只使用 `transform` 与 `opacity`；切换 240 ms；尊重 `prefers-reduced-motion`。

## 桌面结构

- 230 px 左侧收藏夹 rail。
- 中央媒体舞台占余下空间，单个 9:16 媒体完整可见并居中。
- 320 px 右侧作品元数据 rail，使用留白与细分隔线，不使用卡片栅格。
- 媒体列表为垂直 scroll snap，只允许当前可见作品播放。

## 移动结构

- 单列 `100dvh` 沉浸流；顶部与底部遵守安全区。
- 上下滑切作品；图集在作品内部左右滚动。
- 右侧只保留归档、来源、信息三个真实动作，不显示虚构社交计数。
- 收藏夹从底部抽屉切换，触控目标不小于 44 px。

## 首屏可见文字白名单

`留影`、`全部归档`、`想去的地方`、`好看的美女`、`下载任务`、`同步状态`、`设置`、`搜索归档`、`已连接`、`5 分钟自动同步`、作品作者与文案、`来自`、`本地原片`、`切换收藏夹`。

设置、登录、空状态与错误提示属于功能必须内容，可在对应状态出现，不在媒体首屏叠加营销文案。
