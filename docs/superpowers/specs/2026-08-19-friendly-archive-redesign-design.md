# “留影”友好式全站 UI 重构设计

## 目标

把当前偏暗色、绝对定位为主的界面重构为明亮、圆润、有实体按压感的友好式产品界面。视觉语法借鉴优秀语言学习产品的“强层级、明快状态、触感反馈”，但不使用其商标、名称、角色、插画或其他品牌资产。

同时解决电脑端在不同宽度下中央媒体被压缩、右侧信息和翻页按钮依赖绝对定位、顶栏覆盖内容的问题。

## 根因

- `FeedPage` 把整个页面锁定为 `100dvh` 并隐藏溢出，顶栏、右侧详情和翻页按钮都通过绝对定位堆叠。
- 左轨道、中央媒体和右侧信息没有共享一个明确的桌面网格，`xl` 附近的宽度切换会突然增加 310px 侧栏。
- 主要视觉规则散落在 JSX 内联 Tailwind 字符串中，导致登录、抽屉、下载面板和媒体页各自使用不同的暗色表面。

## 视觉概念基准

- 桌面：`docs/design/liuying-friendly-desktop-concept.png`
- iPhone：`docs/design/liuying-friendly-mobile-concept.png`

两张图是色彩、间距、圆角、按压感和响应式构图的基准，不是功能需求源。图中与现有产品不一致的删除、分享、点赞、评论、虚构容量和虚构文件信息不实现。页面只显示真实 API 数据和已有功能。

## 设计系统

### 颜色

- 页面底色：`#F7F7F7`
- 主表面：`#FFFFFF`
- 主文字：`#3C3C3C`
- 次文字：`#777777`
- 线框：`#E5E5E5`
- 强线框/实体阴影：`#D2D2D2`
- 品牌绿：`#58A84A`，深色按压边：`#3E8535`
- 辅助蓝：`#2F9ED5`
- 警告橙：`#D88920`
- 错误红：`#D95454`
- 媒体舞台：`#202326`，绝不使用纯黑

绿色是唯一主强调色；蓝、橙、红仅用于语义状态。不使用渐变、霓虹外发光、紫色或玻璃模糊。

### 形状和物理反馈

- 主面板圆角 24px，常规卡片 18px，按钮 14–18px。
- 可交互主按钮使用 2px 描边和 4px 实色底边；按下时只用 `transform: translateY(3px)` 并减少底边。
- 不在每组内容外套卡片；侧栏内部优先使用留白和分隔线。
- 所有触摸目标不小于 44x44px，保留 `focus-visible` 轮廓。

### 字体和图标

- 使用 `Geist, SF Pro Display, PingFang SC, Noto Sans SC, system-ui` 无衬线栈。
- 标题依靠 700–800 字重和紧凑字距，不使用夸张超大字号。
- 继续使用已安装的 `@phosphor-icons/react`，导航图标默认 22px，表意图标 18–20px，选中态用 `fill` 或 `duotone` 权重。
- 不使用 emoji、文字箭头或外部图标库。

## 响应式布局

### 大桌面（≥1280px）

- 顶层使用 CSS Grid：`264px minmax(520px, 1fr) 340px`，最大宽度 1720px，居中。
- 左轨道和右信息栏都在网格流中，不覆盖中央内容。
- 中央区域再分为顶部工具栏、媒体舞台和底部导航。媒体舞台填满剩余高度，9:16 媒体使用 `object-contain`，不裁切。
- 右栏显示真实作者、描述、归档日期、收藏夹和本地原文件状态。

### 小桌面/平板（960–1279px）

- 网格改为 `240px minmax(0, 1fr)`。
- 右侧详情不占固定列，通过现有详情抽屉打开。
- 顶栏仍在文档流中，中央媒体不得产生水平滚动。

### 移动（<960px）

- 保留竖向滑动切换作品的核心交互，但媒体卡与安全区、顶部选择器和底部导航之间有明确间距。
- 底部导航使用白色实体表面、2px 顶边和选中绿色；不用玻璃模糊。
- 媒体内部可保留深色遮罩来保证标题可读，但页面导航和抽屉统一为明色。
- 横屏高度 ≤500px 时收紧顶底导航，图标仍保留 44px 点击区。

## 组件范围

### 应用外壳和导航

- `FeedPage` 负责响应式外壳和数据状态，不再用绝对定位组合桌面三栏。
- `CollectionRail` 改为白色导航轨道；选中行使用浅绿背景、绿色图标和实体底边。
- `MobileNavigation` 保持五个真实入口，只改变视觉和选中反馈。

### 媒体浏览

- `FeedCard` 在桌面嵌入中央媒体舞台，在移动端继续快照式分页。
- 桌面上一个/下一个控件进入中央区底部流式工具栏，不再锦上绝对定位。
- 播放、静音、图集滑动、视频进度和自动加载功能保持不变。

### 抽屉、下载和设置

- `ArchiveStatusPanel`、`ItemDetailsSheet`、`MobileSearchSheet` 和收藏夹抽屉使用同一套白色表面、灰色边框、实体按钮和深色文字。
- 下载面板保留真实字节、速度、ETA、状态计数、错误和重试倒计时。进度条为绿色，状态色只在必要标签中出现。
- 面板打开期间的轮询频率保持现有 1s/5s 规则，不增加高频动画。

### 登录和初始设置

- `SetupPage` 和 `LocalLoginPage` 使用双栏或单卡片响应式布局，标签在输入框上方，错误在输入框下方。
- `DouyinLoginPage` 的远程浏览器全屏交互层不改变任何坐标、WebSocket、键盘或手势语义；只重构进入前引导界面和可视控件。

## 动效与性能

- 不新增第三方动画库。
- 只用 CSS `transform` 和 `opacity` 实现 160–220ms 动效，列表不做永久循环动画。
- 保留 `content-visibility` 用于长下载任务列表和非活动媒体卡。
- 支持 `prefers-reduced-motion`，禁止客户端粒子、磁吸跟随、滚动监听器和连续重绘。

## 多语言与可访问性

- 保留现有中英文键集，新增文案必须同时补齐中英文。
- 不以颜色作为唯一状态信号，状态必须有文字或图标。
- 对话框保留 `role="dialog"`、`aria-modal`、明确 `aria-label`；进度保留原生 `progress` 或可访问 `progressbar`。
- 所有只显示图标的按钮必须有可读名称。

## 测试与验收

- 先通过 Vitest/Testing Library 添加会在旧结构上失败的行为测试：桌面工作区有独立中央区和流式详情栏，桌面导航不依赖绝对定位，现有移动入口与下载交互全部保留。
- 完整执行 `npm test -- --run`、`npm run lint`、`npm run build`。
- Browser/IAB 控制已尝试且当前失败为 `agent is not defined`，因此允许使用项目已安装环境中的 Playwright CLI 回退。
- 浏览器验收视口：1440x1000、1280x800、1024x768、430x932、393x852、932x430。
- 检查页面身份、非空白页、无框架错误层、无应用控制台错误、至少一次收藏夹切换、媒体播放/暂停、下载面板展开和移动导航交互。
- 用 `view_image` 直接对比桌面/移动概念图与最新实现截图，并记录布局、字体、颜色、容器、图标、响应式的差异和修复。

## 部署与安全

- 只同步源代码、测试、文档和产品概念图，排除 `.env`、SQLite、归档媒体、Chromium profile、cookie、缓存和构建产物。
- 只重建并替换 `douyin-nas-archive` 服务，不重启其他 NAS 容器。
- 部署后验证 `/health/ready`、主页资产哈希、抖音登录保留、最近应用日志和真实 API 数据。
- 代码修改验证通过后创建本地 checkpoint commit 和新标签。当前仓库没有配置远程，不声称已推送。

## 明确不做

- 不添加删除归档、分享、点赞、评论、暂停队列或取消任务。
- 不更改抖音数据获取、下载器、数据库结构、会话加密或远程浏览器协议。
- 不引入新的字体、图标、CSS 框架、动画库或设计系统依赖。
