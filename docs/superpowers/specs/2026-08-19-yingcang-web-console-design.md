# 影仓 Web 体验与专业控制台设计

## 目标

使影仓在桌面和 iPhone 15 Pro Max 上都具有熟悉的短视频浏览节奏，同时突出“私人媒体库”独有的本地状态、批量归档和运维可观测性。

## 视觉方向

- 默认暗色，保留亮色切换；主色使用影仓自有的冷色调强调色，不复制抖音标识。
- 视频封面是主要视觉资产，UI 表面低对比、少阴影、明确层级；不使用 emoji、CSS 图画或假图标。
- 图标统一来自现有 Phosphor 库，主要状态同时有文字或可访问标签。
- 正文最小 `14px`，重要数字使用 tabular numerals。

## 页面与交互

### 首页与媒体库

- 沉浸视图：单作品占据主区，支持滚轮/滑动切换，右侧是作品操作与本地状态。
- 网格视图：桌面根据宽度显示 3–6 列，移动显示 2 列；支持搜索、来源筛选和批量选择。
- 无限滚动：触发点在距离当前末尾约一个视口处；每个游标只请求一次，新游标生成后可继续触发。按钮只在失败时用于重试。
- 网格对长列表使用虚拟化，不让 DOM 节点随数据无限增长。

### 我的

顶级 tab 为作品、喜欢、收藏、观看历史、稍后再看和我的预约。收藏下有收藏夹、视频、音乐、合集和短剧。每个 tab 都显示同步时间、完整度和可用操作，不用空白页代替未实现或权限受限状态。

### 关注与创作者

- 桌面使用主从结构：左侧是可搜索、可虚拟化的关注列表，右侧是当前创作者档案与已发现作品。
- 创作者页显示远程声称作品数、本地发现数、已下载数、占用空间，以及“归档全部”和“自动追更”。
- 移动端将关注列表和创作者详情分为两层导航。

### 专业控制台

首屏显示：NAS 总空间/可用空间/影仓占用，当前和近 15 分钟下载速度，CPU，内存，队列深度，运行中/重试/失败数，同步完整度与抖音会话状态。

详情区包含：

- 近 24 小时速度、CPU、内存和磁盘趋势。
- 当前 batch 进度、单项进度、ETA 和实际文件路径。
- 来源完整度表，按缺口和最后成功时间排序。
- 最近错误事件，显示可操作的解决方向，不暴露敏感信息。

## 状态与实时更新

- 任务、速度和健康状态优先使用 Server-Sent Events；断线时自动回退到至少 2 秒且具有退避的轮询。
- 不用 250ms 全页截图或全量状态刷新实现“实时”。
- 列表请求保留上一批可见数据，使用局部 skeleton 和错误重试，避免整页闪烁。

## 多语言与可访问性

- 所有新文案同时提供 `zh-CN` 和 `en`，默认中文。
- 键盘可到达主要导航、tab、下载操作和弹层关闭按钮，焦点样式可见。
- 尊重 `prefers-reduced-motion`，状态不只依赖颜色。

## 验收

- 网格在至少三个游标后仍自动加载，请求无重复。
- 沉浸视图和网格之间切换保留当前作品位置。
- 专业控制台的数字来自真实本地 API，不使用前端随机或硬编码假数据。
- Chrome 桌面及 `430 x 932` 视口通过主要任务链路与视觉对比验收。
